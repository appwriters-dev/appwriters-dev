Flutter is a modern application development framework from Google. It is a cross-platform framework, which means a single codebase can be used to create applications for Android, iOS, the web, and Windows, macOS and Linux desktops. Flutter apps are written in the Dart programming language, which we discussed and practiced in previous chapters. In the following chapters, we will learn the fundamentals of Flutter and create a number of applications.

In this chapter, we'll go over the fundamentals of Flutter and how to get started with the Flutter framework.
