Modern applications are interconnected with many services. All of that happens through APIs. In this chapter we will learn how to make API calls and how to handle asynchronous programming. We will also learn how to parse JSON data.

## Objectives

- Understanding Asynchronous Programming
- Understanding and using REST API
- Fundamentals of API
- Using the http package to make API calls
- Parsing JSON
