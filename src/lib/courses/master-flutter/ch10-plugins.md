---
id: ch10-plugins
title: Plugins to Access Native Functionalities
description: Learn to use plugins to access native device functionalities in your Flutter application.
---

Plugins are Dart packages that also contain platform-specific (native) code for Android, iOS, web or desktop. They are used to access native functionalities. For example, the [path_provider](https://pub.dev/packages/path_provider) package is used to find commonly used locations on the device, such as the temporary and application documents directories.
