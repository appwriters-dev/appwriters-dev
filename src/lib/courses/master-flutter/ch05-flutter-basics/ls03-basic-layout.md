In this lesson we will learn how to create a basic layout with multiple widgets. We will learn `Row`, `Column`, `Stack` widgets and other related widgets.

## Projects

### 1. Basic Layout

Build the following layout using `Row`, `Column`, `Padding` and `Image` widgets.

![Basic layout](/images/courses/master-flutter/ch05-ls03-pr-01.png)

> **Tip**: Use `Image.network` to display your image. Don't forget to post a screenshot to your social networks with the hashtag #masterflutter after you are done.

### 2. Product Card

Build a product card that displays product image, title, price and rating. Use `Row`, `Column`, `Padding`, `Image` and `Icon` widgets.

### 3. Write a detailed article

Write a detailed article on one of these widgets: Stack, Row or Column. The article should include the following:

- What is the widget for?
- How to use it?
- How to use it with other widgets?
- How to customize the widget?
